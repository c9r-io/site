思路

这几个项目共通的地方，说得足够直白，好让它有被证伪的余地。

让 agent 干活

不是在人类作者旁边做补全 —— agent 从计划一路做到补丁。真正需要工程的，是它周围的那一圈东西。

验证决定节奏

写代码从来不是瓶颈，知道代码对不对才是。生成速度一旦超过验证速度，多出来的只是一堆没人看过的改动。

默认留在本机

会话、状态和源码都留在产生它们的那台机器上。这里没有哪样东西是要先注册账号才好用的。
